# Яндекс фикс для Atlas Launcher

Виджет для быстрого включения и выключения фикса авторизации в приложениях Яндекса на головном устройстве Geely Atlas 2024.

На виджете только название и тумблер. Размер можно менять по ширине и высоте; для высокой карточки используется вертикальное расположение. Значок приложения остаётся в списке приложений, но отдельного окна настроек нет.

## Скачать и установить

**Версия 1.0.8:** [скачать APK](https://github.com/SergeyVBro/AtlasYandexFixWidget/releases/download/v1.0.8/AtlasYandexFix-1.0.8.apk).

1. Установите APK на ГУ. Предыдущую версию можно обновить без удаления приложения.
2. Добавьте виджет «Яндекс · фикс» на рабочий стол через меню Atlas Launcher.
3. Если ГУ запросит разрешение отладки ADB, подтвердите его и выберите «Всегда разрешать», затем нажмите виджет ещё раз.
4. Нажимайте на карточку, чтобы включать или выключать фикс.

Нужны Android 11 или новее и доступный локальный ADB. Root, MacroDroid и ADBPlugin для работы виджета не требуются.

## Автоматическое подключение

Выбирать автомобиль или вводить порт не нужно. Виджет проверяет локальный адрес `127.0.0.1` на двух портах:

| Профиль | Порт ADB |
|---|---|
| Atlas | `5555` |
| Preface | `7777` |

Сначала используется последний успешный порт. Если подключиться не удалось, проверяется второй. При выборе проверяются ADB-авторизация и наличие пакета, с которым работает фикс. Поиск сам по себе не включает и не выключает фикс. Рабочий порт запоминается автоматически.

Первое системное разрешение отладки нужно подтвердить на ГУ. Telnet и произвольные порты не поддерживаются. Определение порта выполняется при обращении к ADB, постоянного поиска в фоне нет.

Поддержка порта `7777` не означает подтверждённую совместимость самого фикса с Preface: другая модель должна иметь подходящий системный пакет. Версия 1.0.8 на реальных ГУ пока не проверена. На эмуляторе подтверждены чтение состояния через оба порта и возврат на `5555` после отказа `7777`; переключение через тестовый маршрут `7777` полностью не подтверждено — одна попытка завершилась по лимиту 8 секунд.

## Как работает

Включение отправляет через локальное ADB команду:

```sh
am force-stop com.autolink.diminteraction
```

На Atlas пакет системный и имеет флаг `PERSISTENT`, поэтому его процесс может оставаться активным. Состояние фикса определяется по флагу пакета `stopped`: `true` — включён, `false` — выключен. Выключение снимает этот флаг через системный PackageManager с правами авторизованного ADB shell, без root.

Состояние читается при запуске/восстановлении виджета и при переключении. Перед командой проверяется текущее состояние, после — её результат. Постоянного опроса, фоновой службы и постоянного уведомления нет. Внешние изменения состояния отобразятся при следующем чтении.

Тумблер показывает состояние фикса, а не результат авторизации в Яндексе. Серое промежуточное положение означает, что состояние неизвестно; при ошибке переключения появляется короткая подсказка. Во время выполнения команды тумблер затемняется, повторные нажатия игнорируются.

Виджет не включает фикс автоматически после загрузки.
